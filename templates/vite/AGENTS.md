# AIエージェント向け開発ガイド

このガイドは、`vite-starter` プロジェクトで作業するAIエージェント（あなた）に向けたコンテキストと指示を提供します。

## プロジェクト概要

Viteを使用したモダンな静的サイト制作テンプレートです。高いパフォーマンスとクリーンなコード標準に焦点を当てています。

- **フロントエンドツール:** Vite
- **パッケージマネージャー:** pnpm
- **ツールバージョン管理:** mise (`.mise.toml`)
- **リント & フォーマット:** Biome (JS/CSS), Markuplint (HTML)
- **Gitフック:** Lefthook

---

## 1. 開発コマンド

### 環境セットアップ

- 依存関係のインストール: `pnpm install`
- Gitフックのセットアップ: `pnpm prepare`
- miseによるツールインストール: `mise install`

### 主要スクリプト

| タスク                 | コマンド                                  |
| :--------------------- | :---------------------------------------- |
| 開発サーバー起動       | `pnpm dev`                                |
| 本番ビルド             | `pnpm build`                              |
| ビルド結果のプレビュー | `pnpm preview`                            |
| **全問題の自動修正**   | `pnpm fix` (Biome fix + Markuplintを実行) |
| フォーマットのみ       | `pnpm format`                             |
| リントのみ（書き換えない） | `pnpm lint`                           |
| 全チェック（書き換えない） | `pnpm check`                          |
| HTMLリント             | `pnpm lint:html`                          |

### テスト

_注: 現在テストフレームワークはインストールされていません。追加する場合は Vitest を推奨します。_

## 2. コーディングガイドライン

### 基本原則

- **モダン標準:** ES6+ の機能を使用してください。jQuery などのレガシーライブラリは避けてください。
- **パフォーマンス:** バンドルサイズを小さく保ち、プロアクティブに画像を最適化してください。
- **一貫性:** Biome のルールに厳密に従ってください。

### JavaScript

- **命名規則:**
  - 変数・関数: `camelCase`
  - クラス: `PascalCase`
  - 定数: `SCREAMING_SNAKE_CASE`
- **インポート:**
  - 設定されている場合は非相対パス（non-relative）を使用し、それ以外はクリーンな相対パスを使用してください。
  - インポート時の `.js` 拡張子は省略可能です（Viteが処理します）。
  - インポート順序は Biome が保存時または `pnpm fix` 実行時に自動で整列します。
- **エラーハンドリング:**
  - 非同期操作には `try...catch` を使用してください。
  - 本番コードでの `console.log` は避けてください。必要な場合は `// biome-ignore lint/suspicious/noConsole: <explanation>` を使用してください。
- **DOMアクセス:** `querySelector` や `addEventListener` を優先してください。実行前に DOM がロードされていることを確認してください。

### CSS

- **手法:** CSS Cascade Layers (`@layer`) を使用しています。
- **構造:**
  - `base`: リセットとベース要素のスタイル。
  - `layout`: グローバルなレイアウトコンポーネント。
  - `components`: 特定のUIコンポーネント。
- **命名規則:** 複雑さが増す場合は、クラス名に BEM ライクな命名規則を採用してください。
- **フォーマット:** Biome がプロパティのソートとフォーマットを処理します。

### HTML

- **標準:** 妥当な HTML5 を使用してください。
- **リント:** `.markuplintrc` で定義された `markuplint` のルールに従ってください。
- **アクセシビリティ:** 高い ARIA 標準と適切なセマンティックタグを維持してください。

---

## 3. フォーマット & リント (Biome)

プロジェクトでは JS と CSS の両方に Biome を使用しています。

- **インデント:** スペース 2 つ
- **引用符:** ダブルクォート
- **セミコロン:** 常に付与
- **行の長さ:** 150文字

エージェントはタスクを完了する前に必ず `pnpm fix` を実行し、コード品質を確保してください。

---

## 4. 振る舞いルール

- **日本語のみ:** ユーザーへの回答は常に日本語で行ってください。
- **プロアクティブ:** 変更によってドキュメントや設定の更新が必要な場合は、指示を待たずに行ってください。
- **安全性:** セキュリティ関連の設定を削除しないでください。
- **正確性:** ファイルを編集する際は、Biome のルールに従い正確なインデントを維持してください。

---

## 5. ファイル構造

- `src/index.html`: エントリポイント
- `src/assets/js/app.js`: メイン JS エントリ
- `src/assets/css/index.css`: メイン CSS エントリ
- `public/`: 静的資産（faviconなど）
- `vite.config.js`: Vite 設定
- `biome.json`: Biome 設定
